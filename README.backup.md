## Теория (что рассказывать)

### 1. Зачем нечёткая логика
В классической логике значение либо принадлежит множеству (1), либо нет (0). Но «высокая влажность» — понятие размытое: 70 % уже в какой-то мере высокая, а 55 % — чуть-чуть. Нечёткое множество задаётся функцией принадлежности μ(x) ∈ [0;1]. Одно значение может одновременно относиться к нескольким термам (например, 18 °C — немного «низкая», сильно «умеренная», чуть-чуть «высокая»). Это даёт плавные переходы.

### 2. Лингвистические переменные
- Вход: **Температура** (−30…40 °C): низкая, умеренная, высокая; **Влажность** (0…100 %): низкая, средняя, высокая; **Давление** (960…1060 гПа): низкое, среднее, высокое.
- Выход: **Вероятность осадков** (0…100 %): низкая, средняя, высокая.
- Функции принадлежности — трапеции `(a,b,c,d)` и треугольники (`b=c`). μ=0 вне [a;d], μ=1 на [b;c], линейно между.

### 3. Алгоритм Мамдани (5 шагов)
1. **Фаззификация.** Для чёткого входа x считаем μ для каждого терма. Пример: влажность 80 % → μ(высокая)=1.0, μ(средняя)=0.
2. **Оценка условий правил.** `AND` = **min**, `OR` = **max** степеней принадлежности. Результат — степень срабатывания правила α.
3. **Импликация.** Выходной терм правила «обрезается» на уровне α: `min(α, μ_терма(y))`.
4. **Агрегация.** Усечённые термы всех правил объединяются оператором **max** → одна итоговая фигура μ_agg(y).
5. **Дефаззификация — центроид** (центр тяжести):
   `y* = Σ y·μ_agg(y) / Σ μ_agg(y)` — берётся по сетке из 1001 точки на [0;100]. Получается число — вероятность осадков в %.

Если ни одно правило не сработало (Σμ_agg = 0), центроид не определён — программа сообщает об этом, а не выдаёт «0».

### 4. База правил (9 штук)
| № | Условие | Осадки |
|---|---|---|
| 1 | T низкая И влажность высокая | высокая |
| 2 | T умеренная И влажность высокая | высокая |
| 3 | T высокая И давление высокое | низкая |
| 4 | T высокая И влажность низкая | низкая |
| 5 | давление низкое И влажность высокая | высокая |
| 6 | давление среднее И влажность средняя | средняя |
| 7 | T низкая И давление низкое | высокая |
| 8 | T умеренная И давление высокое | низкая |
| 9 | T высокая И влажность средняя | средняя |

Физический смысл: низкое давление и высокая влажность — признаки циклона и дождя; высокое давление и жара/сухость — ясная погода.

### 7. Вопросы, которые могут задать
- *Почему min для AND?* Это стандартная t-норма: условие истинно настолько, насколько истинна самая слабая часть.
- *Чем Мамдани отличается от Сугено?* У Мамдани выход — нечёткое множество (нужна дефаззификация), у Сугено — линейная функция/константа.
- *Почему центроид?* Учитывает всю форму агрегированной фигуры, даёт плавный результат.
- *Что если несколько правил дают один терм?* Объединяются через max при агрегации.
